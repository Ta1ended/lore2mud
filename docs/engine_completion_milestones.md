# Engine Completion Milestones

_Last updated: 2026-07-28_

本文件定义公共引擎从当前状态到功能完备的里程碑路线。每个里程碑是一个可独立验证的
纵向切片，完成后更新本文件和相关交接记录。

## M1: 确定性死亡恢复 ✅

- **状态**: 已完成
- **日期**: 2026-07-28
- **内容**: `World.recover()` 将死亡玩家传送回起始房间并恢复满血；`_require_alive()`
  统一门禁覆盖 10 个修改型方法；命令层死亡门禁（`_DEAD_ALLOWED`）；save/load 往返
  验证；55 项新测试。
- **验收**: 470 项测试通过、编译、内容校验、安全扫描、真实 CLI 冒烟。
