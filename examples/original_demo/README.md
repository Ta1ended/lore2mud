# 微光边站

这是 lore2mud 自带的完全原创演示内容包，只用于验证移动、拾取、背包、
确定性战斗、升级、消耗品、装备和任务闭环。它不引用任何第三方小说、角色或
世界观。

推荐试玩顺序：

```text
look
take item_spark_lantern
take item_linglu_pill
take item_crystal_blade
equip item_crystal_blade
status
go east
go east
attack monster_ash_mite
attack monster_ash_mite
unequip
status
quests
quit
```
